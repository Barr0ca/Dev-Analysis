# Informação sobre os arquivos

Informa o que cada arquivo da pasta `visualization` recebe em sua estrutura.

| Arquivo | Responsabilidade |
| - | - |
| `charts.py` | Gráficos de barras, linhas e comparações, incluindo os da classificação, do k-NN, da MLP e do SVM. |
| `distributions.py` | Histogramas, boxplots e análise de distribuições. |
