# Informação sobre os arquivos

Informa o que cada arquivo da pasta `classifiers` recebe em sua estrutura.

| Arquivo | Responsabilidade |
| - | - |
| `naive_bayes.py` | Classificação de `Overall_Impact` com Naive Bayes gaussiano e validação cruzada. |
| `tree_decision.py` | Classificação com árvore de decisão, hiperparâmetros por `GridSearchCV` e validação cruzada. |
| `knn.py` | Classificação com k-NN, valor de `k` por `GridSearchCV` e validação cruzada. |
| `mlp.py` | Classificação com rede neural MLP, hiperparâmetros por `GridSearchCV` e validação cruzada. |
| `svm.py` | Classificação com SVM, hiperparâmetros por `GridSearchCV` e validação cruzada. |
