# Informação sobre os arquivos

Informa o que cada arquivo da pasta `preprocessing` recebe em sua estrutura.

| Arquivo | Responsabilidade |
| - | - |
| `clean_data.py` | Seleciona as colunas numéricas e preenche os valores ausentes. |
| `standardize_data.py` | Padroniza os dados numéricos para a mesma escala. |
